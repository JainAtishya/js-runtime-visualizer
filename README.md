# JavaScript Runtime Visualizer

An interactive browser-based tool for visualizing how JavaScript code executes.

JavaScript Runtime Visualizer breaks down program execution into the major components of the JavaScript runtime, including the call stack, Web APIs, microtask queue, task queue, promises, and event loop.

The project is built from scratch using HTML, CSS, and Vanilla JavaScript, including a custom tokenizer and parser for analyzing JavaScript source code.

## Features

- Write and run JavaScript directly in the browser
- Visualize execution step by step
- Visualize the Call Stack
- Visualize Web API operations
- Visualize Microtask and Task Queues
- Visualize Promise execution
- Visualize Event Loop behavior
- View console output
- Detect and display syntax errors
- Save and manage JavaScript programs
- Responsive interface for different screen sizes
